# deep-learning-note

这是一个记录我学习深度学习过程的仓库，主要包括笔记、代码复现和一些独立的小实验。

这里的内容不追求做成完整教程，更像是我的学习轨迹:
- 跟着经典教材和课程把核心内容过一遍
- 自己动手实现基础模型和训练流程
- 用 PyTorch 复现常见深度学习模型
- 在兴趣方向上做一些延伸实验和“瞎折腾”

## 我学了什么

目前主要学习和实践了这些内容:

- 深度学习基础概念
  - 感知机、激活函数、损失函数、梯度下降、反向传播
- 神经网络训练方法
  - 参数初始化、优化器、Dropout、BatchNorm、过拟合与欠拟合
- 卷积神经网络
  - 卷积、填充、步幅、池化、多通道卷积、LeNet、AlexNet、VGG、NiN、ResNet、GoogLeNet
- 计算机视觉任务
  - 数据增强、微调、目标检测、锚框、SSD、语义分割、FCN、风格迁移
- 序列模型与自然语言处理
  - 序列模型、语言模型、RNN、GRU、LSTM、Seq2Seq、Attention、Transformer、BERT
- 图神经网络与自动机器学习的一些初步尝试

## 我做了什么

这个仓库里的内容大致分成几部分:

### 1. `深度学习入门`

这一部分主要是跟着《深度学习入门》做的实现和练习，包括:

- 用 Python / NumPy 实现感知机、三层神经网络、损失函数、梯度下降
- 手写两层神经网络和误差反向传播
- 实验不同参数初始化方式和优化器效果
- 练习卷积层、`im2col` 和简单的卷积网络训练

这部分对我理解“神经网络到底是怎么一步一步算出来的”帮助很大。

### 2. `动手学深度学习pytorch版`

这一部分以 notebook 为主，按章节记录了我用 PyTorch 学习和复现模型的过程，包括:

- 线性回归、Softmax、多层感知机等基础模型
- CNN 系列模型: LeNet、AlexNet、VGG、NiN、ResNet、GoogLeNet
- 训练技巧: 权重衰退、Dropout、BatchNorm、模型选择、GPU 使用
- 视觉任务: CIFAR-10 分类、ImageNet Dogs、目标检测、语义分割、样式迁移
- NLP 相关: RNN、GRU、LSTM、机器翻译、Attention、Transformer、BERT

这部分更偏“边学边做”，重点是把课本里的东西自己跑通、改写并理解。

### 3. `深度学习基础与概念`

这一部分记录了一些更偏概念理解和基础整理的内容。

### 4. `瞎折腾`

这里放的是一些偏兴趣驱动的小实验，不一定系统，但更接近“自己想试试看能不能做出来”:

- 使用 GNN 预测分子溶解度
- 用 AutoGluon 做一些有趣的小任务
- 使用 CVAE 做宋词续写
- AI 基础实验课中的卷积 + 遗传算法实验

这一部分对我来说更像是把学过的内容往具体问题上套，看看能不能真的跑起来。
